## 🛡️ Key Privacy Commitments

1. **Minimal Data Collection:** We collect Name, Email, and Phone solely for authentication, quotation generation, and milestone tracking.
2. **Zero Third-Party Advertising:** No ad tracking networks, data brokers, or monetization libraries are integrated.
3. **Document Attachments:** Document picker access is used strictly when you choose to attach design wireframes, briefs, or project PDFs to a quotation request.
4. **Encrypted Communications:** All database and API communications are encrypted via HTTPS / TLS 1.3.
5. **Account Deletion:** Users retain the full right to export or request complete erasure of their account data at any time.
